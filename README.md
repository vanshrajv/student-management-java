# 🎓 Student Management App

A simple **Student Management App** created using Java.

## 📌 Features

- Enter student name
- Display roll number
- Display CGPA
- Display student status
- Simple console-based interface

## 🛠️ Technologies Used

- Java 21
- Scanner
- Variables
- System.out.println()

## 📂 Project Structure

│
└── StudentApp.java
